POST/api/v1/geocode

Convertir une adresse en coordonnées GPS

Corps JSON requis

addressAdresse, 3 à 500 caractères

Nécessite un token GreenLine et une clé serveur GOOGLE_GEOCODING_API_KEY.

Exemple de requête

{ "address": "10 rue de Rivoli, Paris" }
200 Succès
{
  "message": "Adresse convertie en coordonnées GPS.",
  "errors": [],
  "data": {
    "formatted_address": "10 Rue de Rivoli, 75001 Paris, France",
    "latitude": 48.8556,
    "longitude": 2.3653
  },
  "pagination": null
}

Erreurs possibles : 401 token manquant/invalide, 404 adresse introuvable, 422 corps invalide, 429 quota atteint, 502 Google indisponible, 503 clé non configurée.

POST/api/v1/eta/locations

ETA entre adresses et/ou véhicules

Corps JSON requis

Pour origin et destination, fournissez exactement un champ : parc_id ou address.

origin.parc_idIdentifiant de parc
origin.addressAdresse
destination.parc_id / addressUn seul requis

Formats parc acceptés : PF-1233, ST-1233, CO-1233, ME-1233. Un parc doit être présent dans Hiboo et fournir une position GPS exploitable. Les adresses utilisent Google Geocoding.

Exemple mixte

{
  "origin": { "parc_id": "PF-1233" },
  "destination": { "address": "10 rue de Rivoli, Paris" }
}
200 Succès
{
  "message": "ETA calculée à partir des deux emplacements.",
  "errors": [],
  "data": {
    "eta_at": "2026-11-19T14:30:00Z",
    "duration_seconds": 900,
    "distance_meters": 4200,
    "encoded_polyline": "...",
    "origin": { "source_type": "parc_id", "source": "PF-1233", "latitude": 48.85, "longitude": 2.35 },
    "destination": { "source_type": "address", "source": "10 Rue de Rivoli, Paris", "latitude": 48.85, "longitude": 2.36 }
  },
  "pagination": null
}

Les quatre combinaisons parc/parc, parc/adresse, adresse/parc et adresse/adresse sont acceptées. Une télématique absente ou sans GPS renvoie 422. Les erreurs Google/Hiboo renvoient 502 ou 503.

POST/api/v1/eta

Calculer une ETA routière

Corps JSON requis

Coordonnées WGS84; latitude −90 à 90, longitude −180 à 180.

origin.latitudeRequis
origin.longitudeRequis
destination.latitudeRequis
destination.longitudeRequis

Exemple de requête

{
  "origin": { "latitude": 48.8566, "longitude": 2.3522 },
  "destination": { "latitude": 48.8584, "longitude": 2.2945 }
}
200 Succès
{
  "message": "ETA calculée avec succès.",
  "errors": [],
  "data": {
    "eta_at": "2026-11-19T14:30:00Z",
    "duration_seconds": 900,
    "distance_meters": 4200,
    "encoded_polyline": "..."
  },
  "pagination": null
}

Erreurs possibles : 401 token manquant ou invalide, 404 aucun itinéraire, 422 paramètres invalides, 429 quota atteint, 502 erreur du service Google, 503 identifiants Google absents.

POST/api/v1/telematics/check

Vérifier la présence dans Hiboo

Corps JSON

Renseignez l’un des deux champs. Les listes acceptent jusqu’à 100 véhicules.

parc_idUn identifiant
parc_idsListe d’identifiants

Formats acceptés : PF-1233, ST-1233, CO-1233, ME-1233. La casse est normalisée.

Exemple de requête

{ "parc_ids": ["PF-1233", "ST-1233"] }
200 Succès
{
  "message": "Vérification télématique effectuée.",
  "errors": [],
  "data": { "vehicles": [
    { "parc_id": "PF-1233", "equipped": true, "equipment_id": 1 },
    { "parc_id": "ST-1233", "equipped": false, "equipment_id": null }
  ] },
  "pagination": null
}

Erreurs possibles : 401 token manquant ou invalide, 422 identifiant invalide, 429 quota atteint, 502 Hiboo indisponible, 503 identifiants Hiboo non configurés.

POST/api/v1/telematics/positions

Récupérer les dernières positions GPS

Corps JSON

Identique à la vérification télématique.

parc_idUn identifiant
parc_idsListe, maximum 100

Les véhicules absents de Hiboo retournent equipped: false et position: null.

Exemple de requête

{ "parc_id": "PF-1233" }
200 Succès
{
  "message": "Dernières positions récupérées.",
  "errors": [],
  "data": { "vehicles": [{
    "parc_id": "PF-1233",
    "equipped": true,
    "position": {
      "date": "2026-11-19T14:25:00Z",
      "latitude": 48.8566,
      "longitude": 2.3522,
      "altitude": null,
      "speed": 0,
      "heading": null
    }
  }] },
  "pagination": null
}

Un véhicule équipé sans relevé GPS retourne equipped: true et position: null. Erreurs possibles : 401, 422, 429, 502, 503.

ADMIN/api/v1/admin/*

Gestion protégée par X-Admin-Token

Routes de gestion

GET /tokensLister les tokens
POST /tokensCréer { name }
POST /tokens/{id}/revokeRévoquer un token
GET /usage?date=YYYY-MM-DDConsulter les compteurs UTC
GET /limitsLire les quotas
PUT /limitsModifier les quotas

Le token administrateur est défini par API_ADMIN_TOKEN. Les routes sont aussi documentées dans Swagger.

Configurer les limites

{
  "default_daily_limit": 1000,
  "endpoint_limits": {
    "/api/v1/eta": 2000,
    "/api/v1/telematics/check": null
  }
}

Une valeur null supprime la surcharge de route et rétablit la limite générale. Le quota est appliqué séparément à chaque token et endpoint.

Format commun des réponses

Toutes les routes JSON utilisent la même enveloppe. Les réponses d’erreur conservent leur code HTTP et remplissent errors.

messageRésumé lisible du résultat
errorsListe vide en cas de succès
dataDonnées métier, ou null en erreur
paginationMétadonnées, ou null si non paginé
422 Exemple d’erreur de validation
{
  "message": "Les données envoyées sont invalides.",
  "errors": [{
    "code": "value_error",
    "message": "Chaque parc_id doit respecter le format attendu.",
    "field": "body"
  }],
  "data": null,
  "pagination": null
}
